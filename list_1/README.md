# List 1 Overview

The structure of this list is as follows:

- `python_code/`: Contains Python implementations of machine learning algorithms and statistical analysis.
    - `bivariate_classifier.py`: Binary classification implementation.
    - `multivariate_linear_regression.py`: Multivariate regression analysis.
    - `plots.py`: Visualization utilities.
    - `requirements.txt`: List of Python dependencies required for the project.
    - `data/`: Directory containing input datasets for each algorithm.
        - `bivariate_classifier/`: Classification dataset.
        - `multivariate_linear_regression/EGG/`: EGG signal data (11 files).
    - `results/`: Directory storing output results organized by algorithm.
        - `bivariate_classifier/`: Classification metrics and estimates.
        - `joint_pdf/`: Joint probability density function outputs.
        - `multivariate_linear_regression/`: Regression results per EGG file.

- `legacy_report/`: Contains archived analysis and documentation.
    - `question_5.ipynb`: Jupyter notebook with legacy analysis.
    
> [!NOTE]
> Directory `report` and file `questions.pdf` have already been addressed in this project's [main README.md](./../README.md).
