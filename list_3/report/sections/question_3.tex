\section{Question 3}
Perform an experiment testing different kernel functions and hyperparameter configurations 
to obtain the best Support Vector Machine (SVM) classifier for a binary classification task, using a dataset of your choice. 
Don't forget to discuss the results.

\noindent\rule{\textwidth}{.5pt}

\noindent\textbf{Data description.}
The dataset chosen is the Oxford Parkinson's Disease Detection Dataset, 
openly available at \cite{parkinsons_174} (loaded in \texttt{parkinsons.csv}).
It 
``{\itshape is composed of a range of biomedical voice measurements from 31 people, 23 with Parkinson's disease (PD). 
Each column in the table is a particular voice measure, 
and each row corresponds one of 195 voice recording from these individuals (`name' column). 
The main aim of the data is to discriminate healthy people from those with PD, 
according to `status' column which is set to 0 for healthy and 1 for PD}'',
as quoted directly from the authors.

The relatively low number of samples and high number of features play into the strengths of an SVM classifier.
As done in the previous questions (see \cref{fig:data_preprocessing}), 
non-relevant features were dropped (e.g., the name column), 
highly correlated features were removed (see \cref{fig:correlations_pd}),
and the remaining samples shuffled before being the train-validation-test split.
%
\Cref{tab:data_pd} assesses the size and composition of the resulting splits.

As done in the previous questions, the Optuna framework was used to find the best hyperparameters
with respect to overall accuracy on the validation set.
%
The search space and best hyperparameters after 100 trails are shown in \cref{tab:hparams_svm};
the associated model managed to obtain an error rate of 10.42\%.
The confusion matrix obtained on the test set from this model is shown in \cref{fig:confusion_matrix_svm}.
\Cref{tab:results_svm} lists some metrics derived from the results in the matrix.

\begin{table}[!h]
    \centering
    \begin{threeparttable}
    \caption{SVM hyperparameters.}

    \begin{tabular}{ccc}

It is clear that the SVM was a good predictor of PD, 
but its performance on healthy patients is lacking.
% 
As seen previously, this is likely due to the use of an objective function in the validation stage
that favors classes with greater number of samples.

Changing the objective function to consider each class separately but simulneaously 
should prove an improvement to this explorative study.
